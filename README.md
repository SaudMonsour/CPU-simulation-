# محاكاة مسار البيانات في معالج

عرض ثلاثي الأبعاد لمسار البيانات داخل معالج RISC-V من مجموعة التعليمات RV32I. يكتب المستخدم برنامج التجميع، ثم ينفّذه المحاكي تعليمةً تلو أخرى، مع عرض السجلات والذاكرة وحقول التعليمة.

## التصميم
محرك المحاكاة مكتوب بلغة TypeScript ومستقل عن React والرسم الثلاثي الأبعاد. ينتج المحرك لقطة لحالة الجهاز، وتعرضها الواجهة؛ لذلك تبقى منطقية التنفيذ منفصلة عن العرض.

## الإمكانات المنفّذة
- تعليمات الأعداد الصحيحة والجمع والطرح والإزاحة والمقارنة والتحميل والتخزين والفروع والقفز.
- مجمّع يدعم التسميات والتعليمات الشائعة المختصرة، ومفكك لحقول التعليمات.
- وحدة حسابية تستخدم سلسلة حمل صريحة، مع طرح بالمتمم الثنائي وكشف التجاوز.
- كتل مرئية لعداد البرنامج وذاكرة التعليمات ووحدة التحكم والسجلات والوحدة الحسابية وذاكرة البيانات.
- إضاءة للمسارات النشطة، وتنفيذ خطوة بخطوة، وتشغيل وإيقاف وتحكم بالسرعة.
- فحص كل كتلة وعرض قيمها الحالية، مع قاموس للمصطلحات واختبارات للمحرك والمجمّع.

## الحدود الحالية
المحاكي أحادي الدورة، ولا ينفّذ بعد خط أنابيب من خمس مراحل أو التمرير أو التوقفات أو التنبؤ بالفروع. كذلك لا توجد ذاكرة مخبأة متعددة المستويات أو اتساق متعدد الأنوية أو وحدة فاصلة عائمة.

الذاكرة 64 كيلوبايت، معنونة بالبايت وبترتيب الطرف الصغير، ومن دون زمن انتظار. قيمة الدورات لكل تعليمة تساوي 1 بحكم التصميم؛ لا تمثل قياسًا لأداء خط أنابيب.

## الملفات
توجد المحاكاة في `src/engine/`، والتعليمات والمجمّع في `src/isa/`، وحالة التشغيل في `src/state/`، والرسم في `src/scene/`، والواجهة في `src/ui/`. المشروع تطبيق Vite ويحتاج إلى خادم تطوير أو بناء؛ لا يكفي فتح ملف HTML مباشرة.
